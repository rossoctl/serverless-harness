# Experiments moved

The E10-E13 experiment drivers, `EXPERIMENTS.md`, `METAL-RUNBOOK.md`, and `predictions.json` that
used to live in this directory have moved to
[rossoctl/moca-experiments](https://github.com/rossoctl/moca-experiments), with their git history
preserved.

See that repo's `microvm/` directory for the E10 (lifecycle), E11 (density/replenishment), E12
(vsock egress), and E13 (restore capacity/telemetry) drivers, their tests, and their results.
